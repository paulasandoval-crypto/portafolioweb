# Portafolio — Paula Andrea Sandoval

Portafolio de Diseño Gráfico 2026: diseño editorial, campañas visuales, branding, modelado 3D e ilustración.

**Ver en línea:** https://paulasandoval-crypto.github.io/portafolioweb/

## Cómo editarlo
- **Imágenes:** están en `img/`. Para cambiar una, sube otra con el mismo nombre.
- **Textos y proyectos:** al inicio del `<script>` en `index.html` están las listas `SOFTWARE` y `CATEGORIAS`. Para agregar un proyecto, copia uno de los bloques dentro de `proyectos` y cambia sus datos.
- **Colores y tipografías:** variables en `:root`, al inicio del `<style>`.
- **PDF descargable:** `portafolio.pdf`.
